# AIチームの使い方

このリポジトリでClaude Codeを開くと、AIは「部長」として動きます。部長が仕事の内容を見て、5つの部署に振り分けます。

## 部署
| 部署 | 頼むこと（例） |
|---|---|
| 開発部 | 「6-10のボスをもう少し弱くして」「ゲームパッドで遊べるようにして」 |
| PR広報部 | 「新ボスの宣伝ツイートを3案」「TikTok用の15秒動画の構成を作って」 |
| 営業部 | 「Steamのストアページの文章を作って」「価格を決めたい、似た作品と比べて」 |
| 翻訳部 | 「ストアページを英語と中国語にして」 |
| 経理部 | 「Steam登録料100ドル払った、記録して」「5,000本売れたらいくら残る？」 |

## 便利な頼み方
- **「今週の報告をして」**：ロードマップの進み具合と、次にやること、決めてほしいことをまとめます。
- **「〇〇と〇〇を同時に進めて」**：部長が複数の部署に並行して仕事を振ります。
- 部署を指定しなくても大丈夫です。部長が判断します。

## AIが勝手にしないこと
SNSへの投稿、メールの送信、ストアへの申請、支払いは、下書きまで作って止まります。実行はオーナーが確認してから行います。

## 会話が重くなったら
- `/compact`：ここまでの会話を要約して、軽くして続けます。
- `/clear`：会話をリセットします。決まったことは各部署のファイルに残っているので、続きから頼めます。
- `/model`：使うAIのモデルを切り替えます。

## 中身の場所
- 全体のルール：リポジトリ直下の `CLAUDE.md`
- 部署ごとのルールと成果物：`team/` の各フォルダ（それぞれに `CLAUDE.md`）
- 業務マニュアル（スキル）：`.claude/skills/`
- 部署のAI（サブエージェント）：`.claude/agents/`
- ゲームの確認用スクリプト：`game/tools/`

## 外部ツールとの連携（必要になったら）
GmailやGoogleカレンダーなどをつなぐと、「配信者への連絡メールの下書きをGmailに作る」「発売日の予定をカレンダーに入れる」なども頼めるようになります。claude.ai の設定の「コネクタ」から追加できます。
