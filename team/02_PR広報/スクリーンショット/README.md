## 撮り直し方

ゲームを更新したら撮り直す。リポジトリのいちばん上のフォルダで実行する（Chromium と Playwright が必要。クラウド環境には入っている）。

```
bash game/tools/screens-steam.sh ja /tmp/steam-shots/ja
bash game/tools/screens-steam.sh en /tmp/steam-shots/en
bash game/tools/screens-steam.sh zh /tmp/steam-shots/zh
```

- 1言語で5分ほど。8場面ぶんの「候補」が保存先にできる（戦闘は1場面につき14〜30枚、`01_boss_00.png` など）。
- 候補を目で見て一番いい1枚を選び、このフォルダの `ja/01_boss.png` などに上書きコピーする。選ぶときの目安：
  - 2人とも見えている（手前の柱に隠れていない）、敵が写っている、画面が赤くなっていない（ダメージを受けた瞬間は赤くなる）、敵が白く光っていない（弾が当たった瞬間）、「全滅…」「MISSION FAILED」でない。
  - 文字の欠け・はみ出しがないか、拡大して見る。
- 一部の場面だけ撮り直すときは3つ目に番号を書く：`bash game/tools/screens-steam.sh ja /tmp/steam-shots/ja "1 3"`
- 1枚ずつ手順を変えて撮りたいときは `game/tools/screens.js` を直接使う（使える手順はファイルの先頭に書いてある）。例（プロローグ）：
  ```
  node game/tools/screens.js game/houkago-deadline.html /tmp/shots ja "begin;;wait800;;go;;sortie;;wait1500;;snext;;wait600;;snext;;wait600;;snext;;wait600;;snext;;wait600;;snext;;wait600;;snext;;wait600;;snext;;wait600;;snext;;wait600;;wait800;;shot08_story" fresh
  ```
- 英語版の `08_story` は文章が長く、1回目の「次へ」が文字送りの早送りになるため、`snext` を14回にすると同じセリフになる（2026-11-17 撮り直し）。
- `05_weapons` は 2026-11-17 に撮り直した（英語で「装備中」の印が名前に重なっていたのを、名前の横に並べる表示に直したため）。

### 操作のしかた（自動）
- 戦闘はキーボードの入力だけで動かしている（ゲームの中身には手を入れていない）。近い敵の方を向いて撃ち、敵がいなければ右へ進み、スキルは使えるようになったら押す。相棒はゲームのAIのまま。
- 狙撃はマウスを一番近いゾンビに合わせてクリックしている。

### セーブについて
撮影用のブラウザは毎回まっさらな状態で始まり、次のセーブを入れてから撮る（オーナーや遊んでいる人のセーブには触らない）。
- 01・03・05・06：第1部クリア済み・全員Lv30 ＋「第1部をノーマルで遊び終えた人が持っていそうな装備」（第1部で出る★3以下の武器の約6割、第2部の夏・海の防具と水着を除いた防具の約半分。実績はゲーム自身の判定で付く）。各キャラは同じ系統で一番強い武器を装備、防具は制服のまま（06のハルだけゲームの「装備おまかせ」ボタンで着せた）。
- 02・04・07：第1部クリア済み・全員Lv30、武器は最初の装備のまま（強い武器だと敵がすぐ倒れて、画面に群れが残らないため）。
- 08：はじめて遊ぶ状態（セーブなし）。
