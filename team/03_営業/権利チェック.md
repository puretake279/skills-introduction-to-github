# 権利チェック

販売前に全部埋める。わからない項目は「未確認」のままにして、オーナーに聞く。

| 素材 | 作った人・入手先 | 商用利用 | 確認した証拠（規約のURLなど） |
|---|---|---|---|
| キャラのドット絵（ユイ・レイ・ハル・ミオ・ナナ） | 未確認 | 未確認 | |
| シスター服の専用絵 | 未確認 | 未確認 | |
| ゾンビ・ボスの絵 | 未確認 | 未確認 | |
| 背景 | ゲーム内でプログラムが描画 | 可 | 自作のコード |
| 効果音・BGM | ゲーム内でプログラムが合成 | 可 | 自作のコード |
| フォント「DotGothic16」 | Google Fonts | 未確認（SIL Open Font Licenseなら可） | |
| タイトル「放課後デッドライン」 | — | 商標検索：未確認 | |

## AIで作った絵を使っている場合
- 使ったサービス名と、そのサービスの規約で「商用利用」「販売」が認められているかを書く。
- Steamは申請時に、AIで作った素材を使っているかの申告が必要。
