# 収支を記録する

1. `team/05_経理/CLAUDE.md` を読む。
2. オーナーの言葉から、日付・項目・金額・通貨を取り出す。足りない情報は推測せずに聞く。
3. `team/05_経理/収支.md` の「記録」の表の一番下に1行足す。ドル建てなら円換算と使ったレートをメモ欄に書く。
4. 「予定している費用」から実際に払ったものは、そちらの行にも「支払済み（日付）」と書く。
5. 合計（これまでの費用の合計、売上の合計、差し引き）を会話で伝える。
6. 売上の見込みを聞かれたら、前提（価格、本数、手数料、割引）を確認してから計算し、表を書き直す。
