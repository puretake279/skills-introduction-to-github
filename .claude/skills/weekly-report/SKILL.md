# 週次報告

1. `team/00_部長/ロードマップ.md` を読み、終わった項目と残りを数える。
2. 各部署のフォルダで、前回の報告以降に変わったファイルを見る（`git log --since="1 week ago" --name-only`）。
3. 次の形でまとめる。
   - **今の段階**：フェーズ何の、どこまで進んだか（1〜2文）
   - **今週やったこと**：部署ごとに1〜3行
   - **次の1週間でやること**：優先順に3つまで。それぞれ担当部署を書く
   - **オーナーに決めてほしいこと**：選択肢つきで。なければ「なし」
   - **お金**：今週の費用と、これから必要な支払い（`team/05_経理/収支.md` から）
4. `team/00_部長/週次報告/日付.md` に保存し、要点を会話でも伝える。
