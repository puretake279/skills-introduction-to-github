# SNS投稿を作る

1. `team/02_PR広報/CLAUDE.md` のルールを読む。
2. 何を見せる投稿かを1つに絞る（例：新ボス、着せ替え、爆発、キャラの掛け合い、アップデート告知）。
3. 次の形で3案作る。
   - **X**：本文140字以内（日本語）。1行目で絵が浮かぶように書く。ハッシュタグは2〜3個（#インディーゲーム #ゲーム制作 #ドット絵 から選び、必要なら1個足す）。
   - **TikTok／YouTubeショート**：15秒以内の構成表（0〜2秒：銃撃か爆発、2〜10秒：見せたい内容、10〜15秒：タイトルと「ほしいものリストに追加」）。字幕の文も書く。
   - 英語版の本文（海外向け。直訳ではなく自然な英語で）。
4. 使う画面の候補を書く。必要なら `game-check` スキルの `play.js` でスクリーンショットを撮る。
5. `team/02_PR広報/投稿下書き/日付_内容.md` に保存して、オーナーに見せる。**投稿はしない。**

## チェック
- ゲームにない要素や、確かめていない数字が入っていないか。
- 登場人物（高校生）を性的に見せる言い回しや切り取り方になっていないか。
