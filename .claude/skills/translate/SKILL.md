# 翻訳する

1. `team/04_翻訳/CLAUDE.md` と `team/04_翻訳/用語集.md` を読む。
2. 原文に用語集にない固有名詞があれば、先に訳を決めて用語集に足す。
3. 訳す。キャラのセリフは口調を保ち、UIの文字は短く（ボタンは英語で12文字程度まで）。
4. 原文・英語・中国語を表で並べたファイルを、元の部署のフォルダに `〜_翻訳.md` として保存する。
5. 「母語の人の確認が必要な箇所」（言葉遊び、方言、ニュアンスが強いセリフ）に印をつけて、オーナーに伝える。
