# ストアページを作る

1. `team/03_営業/CLAUDE.md` と `team/03_営業/権利チェック.md` を読む。権利に空欄があれば、その旨をオーナーに伝えてから下書きを作る。
2. ゲームの実際の内容を確かめる（章の数、ステージ数、キャラ、武器・防具の数は `game/houkago-deadline.html` の `CHAPTERS`、`STAGES`、`CHARS`、`WEAPONS`、`ARMOR` から数える）。
3. 次を作る。
   - **短い説明**（Steamは300字以内）：1文目でジャンルと舞台、2文目で一番の売り。
   - **詳しい説明**：あらすじ（第1部の結末は伏せる）、遊び方、特徴の箇条書き5〜7個、収録内容（数字つき）。
   - **タグ案**：Steamの公式タグから15〜20個。ジャンル・見た目・テーマの順に、検索されやすいものを上に。
   - **スクリーンショット案**：5〜8枚。1枚目は一番派手な戦闘。どの画面を撮るか、`play.js` の手順つきで。
4. 日本語版を作ったら、翻訳部（`translator` サブエージェント）に英語・中国語版を頼む。
5. `team/03_営業/ストアページ/` に保存する。**ストアへの入力・申請はしない。**
